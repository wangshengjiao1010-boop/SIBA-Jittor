# SIBA-Jittor 现场演示脚本

## AutoDL 开机与连接

1. 登录 AutoDL 控制台，找到保存 `/root/autodl-tmp/SIBA-Jittor` 的 RTX 3090 实例。
2. 选择“有卡模式”开机，并设置 2 小时定时关机。现场训练、Jittor GPU 测试和推理都需要 GPU。
3. 等待实例状态变为“运行中”，在 PyCharm 中使用 Remote SSH 连接；也可以先用终端确认连接：

   ```bash
   ssh -p 39296 root@connect.nmb2.seetacloud.com
   ```

4. 登录后检查 GPU、项目、数据和完整训练权重：

   ```bash
   nvidia-smi
   cd /root/autodl-tmp/SIBA-Jittor
   test -d /root/autodl-tmp/datasets/SIBA/train/ir && echo "training data ready"
   test -d /root/autodl-tmp/datasets/SIBA/test/TNO && echo "test data ready"
   find checkpoints -name 'SIBA_epoch60.pkl' -o -name 'SIBA_epoch60.pth'
   ```

5. PyCharm 中配置 `PytorchDome` 和 `JittorDome` 两个远程解释器。Notebook 若用于展示，也必须分别选择对应环境，不在同一个内核中混用两个框架。
6. 录制结束后回到 AutoDL 控制台关机，并确认实例状态已经变为“已关机”。

## 准备

1. 在 PyCharm 中打开本地项目，并映射远程目录 `/root/autodl-tmp/SIBA-Jittor`。
2. 分别添加 `PytorchDome` 与 `JittorDome` 两个远程解释器，具体步骤见 `docs/PYCHARM_REMOTE_GUIDE.md`。
3. 依次打开：
   - `demo/SIBA_PyTorch_逐模块测试.ipynb`
   - `demo/SIBA_Jittor_逐模块测试.ipynb`
   - `demo/SIBA_Jittor_现场演示.ipynb`
   - `demo/SIBA_PyTorch_Jittor_对齐演示.ipynb`
4. 左侧展开 `official_pytorch/`、`siba_jittor/`、`logs/` 和 `results/`。
5. 预先打开GitHub仓库页面，但不要在视频中输入密码或token。

## 现场顺序

### 1. PyTorch基准，约2分钟

- 打开 `SIBA_PyTorch_逐模块测试.ipynb` 的Outline，展示14个测试部分。
- 运行环境、数据检查和基准生成单元。
- 说明PyTorch从官方权重导出相同输入、初始参数、逐层输出、损失、梯度和一步更新，共707个数组。
- 受控32×32张量仅用于数值测试，不用于训练或论文指标。

### 2. Jittor逐模块检查，约3分钟

- 打开 `SIBA_Jittor_逐模块测试.ipynb` 的Outline，展示18个测试部分。
- 运行全部检查单元，再按顺序展示：
  1. SE与Res-SE；
  2. LayerNorm、归一化和自注意力；
  3. CBSM源图权重；
  4. 四路交叉注意力；
  5. 特征拼接和输出；
  6. Laplacian、Intensity和Sobel损失；
  7. 反向传播；
  8. 梯度裁剪；
  9. Adam一步更新。
- 每个单元显示实际误差，不只显示“通过”。

### 3. 相同初始权重训练，约2分钟

运行：

```bash
cd /root/autodl-tmp/SIBA-Jittor
bash scripts/demo.sh
screen -r kk
```

`bash scripts/demo.sh` 只负责创建后台会话，返回终端后再执行 `screen -r kk` 才能看到逐步输出。训练完成后按 `Ctrl+A`、再按 `D` 退出 screen，不会终止任务。随后执行：

```bash
DEMO_DIR=$(cat logs/latest_demo.txt)
tail -n 20 "$DEMO_DIR/train.log"
ls -lh "$DEMO_DIR"
```

脚本会执行：

1. PyTorch按随机种子2025实例化官方SIBA模型；
2. 导出共享初始权重和SHA256；
3. Jittor加载该权重；
4. 使用真实训练图像运行20步；
5. 输出总损失、Laplacian、Intensity和Sobel损失；
6. 保存新权重、日志和JSON记录。

训练结束后展示：

- `logs/demo_shared_initial/SIBA_seed2025_initial.pth`
- `logs/demo_shared_initial/SIBA_seed2025_initial.json`
- `logs/demo_<时间>/train.log`
- `logs/demo_<时间>/demo_training.json`
- `logs/demo_<时间>/SIBA_demo_step20.pkl`

明确说明：20步训练只证明代码可以运行，不用于最终指标。

### 4. 完整训练结果，约1分钟

- 打开两份60轮 `train.log` 和 `loss_curve.png`。
- 展示Jittor 60轮4,079秒、PyTorch 60轮2,221秒。
- 两框架shuffle实现不同，曲线证明均可收敛，不代表批次一一对应。

### 5. 推理演示，约2分钟

- 在 PyCharm 下方 Terminal 激活 `JittorDome`，运行 `tools/run_inference.py` 的 TNO 完整推理命令。
- 刷新新建的 `results/pycharm_demo_jittor_tno/`。
- 打开2至3张新生成融合图。
- 打开 `summary.json` 和 `timing.csv`。

### 6. 完整结果，约2分钟

- 展示MSRS、M3FD和TNO视觉对比图。
- 展示 `metrics_summary.csv`。
- 展示官方权重下706张Jittor/PyTorch输出最大差1个uint8灰度级。
- 展示原生梯度相对L2约1.05%、一步更新相对L2约6.73%。

### 7. GitHub，约1分钟

- 打开公开仓库首页。
- 展示README中的环境、数据、训练、测试、数值对齐、日志、性能和已知限制。
- 展示 `MIGRATION_LOG.md`、`demo/`、`logs/` 和 `results/`。
- 不需要现场上传；仓库应在录制前完成公开推送。
