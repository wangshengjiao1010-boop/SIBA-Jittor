## 2. SIBA 方法对应到代码

SIBA 的核心不是从中间特征额外学习一套空间 attention 图，而是把源图像本身及其反相图像映射为 query，用于调制另一模态的中间特征。

### 2.1 输入与输出

- 训练输入：单通道红外图 `ir` 和单通道可见亮度图 `vi`，形状 `B×1×H×W`。
- 模型输出：单通道融合亮度 `B×1×H×W`。
- 测试时：将融合亮度与可见图的 `Cb/Cr` 合成 RGB 融合图。
- 默认通道：`1 → 48 → 1`。
- 默认 Self-Attention 深度：1。
- 默认 Cross-Attention 深度：1。
- 参数量：`565,941`，与论文约 `0.565 M` 一致。

### 2.2 前向流程

对应 `siba_jittor/models/SIBA.py:60`：

1. 保存四种源图：
   - `ir_raw = ir`
   - `ir_raw_invert = 1 - ir`
   - `vi_raw = vi`
   - `vi_raw_invert = 1 - vi`
2. 红外和可见光分别经过 `Res_SE`，从 1 通道映射到 48 通道。
3. 两个分支各自经过一个 Self-Attention block，得到 `ir_sa` 和 `vi_sa`。
4. 四个 CBSM 分别从原红外、反相红外、原可见、反相可见生成四个 48 通道 source query：
   - `w_ir`
   - `w_irI`
   - `w_vi`
   - `w_viI`
5. 红外源图 query 作用于可见特征：
   - `ir2vi_ca = CA(vi_sa, w_ir)`
   - `irI2vi_ca = CA(vi_sa, w_irI)`
6. 可见源图 query 作用于红外特征：
   - `vi2ir_ca = CA(ir_sa, w_vi)`
   - `viI2ir_ca = CA(ir_sa, w_viI)`
7. 四路 48 通道特征拼接为 192 通道。
8. `fuse_conv` 通过两个 `Res_SE` 完成 `192→96→48` 融合。
9. `out_conv` 完成 `48→1` 重建，输出融合亮度。

### 2.3 Cross-Attention 的实际计算

对应 `siba_jittor/base_blocks/restormer.py:145`：

- `kv` 来自另一模态的中间特征。
- `q` 来自源图经过 CBSM 得到的 48 通道权重特征。
- `kv` 通过 `1×1 Conv + depthwise 3×3 Conv` 生成 `k` 和 `v`。
- `q/k/v` 重排为 `B×head×channel_per_head×HW`。
- 在 `HW` 维做 L2 normalize。
- `q @ k^T` 产生每个 head 内的通道相关矩阵，再经 softmax。
- attention 与 `v` 相乘后恢复到 `B×C×H×W` 并通过 `1×1 Conv` 投影。

该实现的计算量随空间位置数 `HW` 线性增长，避免标准空间 attention 的 `HW×HW` 矩阵。

## 3. 训练目标

对应 `official_pytorch/train.py` 与 `siba_jittor/train.py`：

`L_total = 10 × L_Laplacian + 0.1 × L_Intensity + 1 × L_Sobel`

### 3.1 Laplacian 联合梯度损失

对应 `JointGrad`：

1. 分别计算红外和可见亮度的归一化 3×3 Laplacian。
2. 比较两者 Laplacian 绝对值。
3. 每个位置保留梯度绝对值更强的模态，但保留其原始正负号。
4. 用 L1 约束融合图 Laplacian 接近该联合目标。

Jittor 没有直接使用 Kornia，因此 `loss/loss.py` 新增显式 `laplacian()`：

- 3×3 kernel：邻域为 1，中心为 -8；
- 按绝对值和归一化；
- reflect padding；
- 按通道分组卷积。

### 3.2 强度损失

对应 `Fusionloss`：

- 取红外与可见亮度的逐像素最大值。
- 用 L1 约束融合图接近该最大强度图。

### 3.3 Sobel 梯度损失

- 使用固定 Sobel-x 和 Sobel-y kernel。
- 梯度强度定义为 `|Gx| + |Gy|`。
- 红外与可见亮度逐像素取较大梯度。
- 用 L1 约束融合图梯度接近该目标。

## 4. Jittor 迁移文件逐个讲解

官方 13 个 Python 文件均有同路径 Jittor 对应文件。下面按实际调用关系说明。

### 4.1 `siba_jittor/args/args_SIBA.py`

该文件与官方版本字节完全一致，定义：

- `ir_path`、`vi_path`：训练数据路径；
- `model_save_path`：权重输出目录；
- `use_gpu_number`：GPU 编号；
- `middle_channel = 48`；
- `epochs = 60`；
- `optim_step = 25`；
- `batch_size = 4`；
- `init_lr = 1e-4`；
- `optim_gamma = 0.5`；
- `weight_decay = 0`；
- `patch_size = 128`。

官方文件重复定义了一次 `patch_size`，迁移原样保留，没有擅自重构。

### 4.2 `siba_jittor/base_blocks/cbsm.py`

CBSM 是 Source Image Channel Boosting and Space Mapping module。

准确结构：

`1通道源图 → Conv3×3(1→48) → PReLU → Conv3×3(48→48) → SE → PReLU`

注意：该模块没有 BatchNorm，也没有 SiLU。它直接从源图生成 48 通道 query 特征，供 Cross-Attention 使用。

迁移差异仅为：

- `torch.nn` 改为 `jittor.nn`；
- `forward()` 改为 `execute()`。

### 4.3 `siba_jittor/base_blocks/SE.py`

`se_module` 的计算：

1. `AdaptiveAvgPool2d(1)` 获得每通道全局统计；
2. `Linear(C→C/reduction)`；
3. ReLU；
4. `Linear(C/reduction→C)`；
5. Sigmoid；
6. 将权重 reshape 为 `B×C×1×1` 并与输入逐通道相乘。

Jittor 版去掉 ReLU 的 `inplace=True`，因为接口不同；输出公式不变。

### 4.4 `siba_jittor/base_blocks/se_resnet.py`

`Res_SE` 是模型的通用卷积残差模块：

1. 输入输出通道不同时，残差支路用 `1×1 Conv`；否则用 Identity。
2. 主支路：`Conv3×3 → PReLU → Conv3×3 → SE/Identity`。
3. `use_res=True` 时主支路与残差相加。
4. 最后经过 PReLU。

用途：

- `ir_conv`、`vi_conv`：1→48；
- `fuse_conv`：192→96→48；
- `out_conv`：48→1，关闭 SE，但保留残差映射。

### 4.5 `siba_jittor/base_blocks/restormer.py`

这是模型主体，包含 8 个官方类和 3 个辅助函数。

#### `normalize`

Jittor 新增函数，用显式公式替代 PyTorch `F.normalize`：

`x / max(sqrt(sum(x²)), 1e-12)`

非退化输入下与 PyTorch 公式一致。

#### `TransformerBlock_SA`

- 可选 `1×1 Conv` 对齐通道；
- `x = x + SelfAttention(LayerNorm(x))`；
- `x = x + Mlp(LayerNorm(x))`。

#### `TransformerBlock_CA`

- 可选 `1×1 Conv` 对齐通道；
- `x = x + CrossAttention(LayerNorm(x), source_query)`；
- `x = x + Mlp(LayerNorm(x))`。

#### `LayerNorm`

- 把 `B×C×H×W` 重排为 `B×HW×C`；
- 在通道维计算 LayerNorm；
- 再恢复为 4D 特征。

#### `Self_Attention`

- `1×1 Conv` 生成 qkv；
- depthwise `3×3 Conv` 注入局部空间信息；
- q/k/v 按 8 个 head 重排；
- q/k normalize；
- 计算通道 attention；
- `1×1 Conv` 投影。

#### `Cross_Attention`

- 中间特征生成 k/v；
- source query 直接作为 q；
- 其余步骤与 Self-Attention 相同。

#### `Mlp`

Restormer 风格 GDFN：

- `1×1 Conv` 扩展为两倍分支；
- depthwise `3×3 Conv`；
- 分成 `x1/x2`；
- `GELU(x1) × x2` 门控；
- `1×1 Conv` 投影回原通道。

#### `BiasFree_LayerNorm` 与 `WithBias_LayerNorm`

- 均在最后一维计算方差；
- `WithBias` 额外计算均值和 bias；
- 权重与 bias 作为公共 Jittor Var 注册到模型参数。

迁移没有改变 head 数、通道、卷积组数、残差顺序或 softmax 维度。

### 4.6 `siba_jittor/models/SIBA.py`

顶层模型由以下模块组成：

| 模块 | 数量 | 作用 |
|---|---:|---|
| `ir_conv`, `vi_conv` | 2 | 两模态浅层特征提取 |
| `ir_sa`, `vi_sa` | 2×1 | 模态内 Self-Attention |
| `weight_ir`, `weight_irI`, `weight_vi`, `weight_viI` | 4 | 从源图及反相图生成 query |
| `ir2vi_ca`, `irI2vi_ca`, `vi2ir_ca`, `viI2ir_ca` | 4×1 | 四路跨模态交互 |
| `fuse_conv` | 2 个 Res_SE | 192→96→48 融合 |
| `out_conv` | 1 个 Res_SE | 48→1 重建 |

初始化只针对 Linear 和标准 LayerNorm；模型中自定义 LayerNorm 的权重初始化已经在类内设为 1/0。官方 checkpoint 的 137 个状态键可完整加载到 Jittor 模型。

### 4.7 `siba_jittor/loader/train_loader.py`

训练加载流程：

1. 对红外目录和可见目录分别 `sorted(glob('*'))`。
2. 只接受 `.png/.jpg/.bmp`。
3. 断言同 index 文件名一致。
4. OpenCV `IMREAD_GRAYSCALE` 读取。
5. 除以 255 并转 float32。
6. 增加通道维，得到 `1×H×W`。
7. 从距边缘 10 像素的位置随机裁剪 `128×128`。
8. 同一对图使用完全相同的 `(x,y)` 坐标。

官方 Kornia `image_to_tensor` 被 NumPy `expand_dims` 替代，数值和 CHW 形状保持。`set_attrs(total_len=...)` 是 Jittor Dataset 必需设置。

必须注意：论文文字描述 RGB→YCbCr 训练，但官方训练 loader 实际读取灰度。Jittor 迁移忠实遵循官方代码。

### 4.8 `siba_jittor/loader/test_loader.py`

测试加载流程：

1. 在数据根目录下寻找 `ir/` 和 `vi/`。
2. 可见图按 RGB 读取并 ToTensor。
3. `RGB2YCrCb` 分解为 Y、Cb、Cr。
4. 红外图按灰度读取并 ToTensor。
5. 返回可见 RGB、Y、Cb、Cr、红外、文件名和原始尺寸。

模型只融合 Y 与红外；Cb/Cr 在测试后处理阶段恢复颜色。

### 4.9 `siba_jittor/loss/loss.py`

包含：

- `laplacian()`：Kornia Laplacian 的显式移植；
- `JointGrad`：Laplacian 联合梯度损失；
- `Fusionloss`：强度损失和 Sobel 损失；
- `Sobelxy`：固定 Sobel kernel。

Sobel kernel 使用 `stop_grad()`，不会作为可训练参数更新。前向 loss 与 PyTorch 最大误差约 `2.98e-6`。

### 4.10 `siba_jittor/compat/pytorch_clip.py`

Jittor 优化器把梯度保存在 `param_group['grads']`。该文件：

1. 收集所有未 stop-grad 参数的梯度；
2. 分别计算每个梯度的 L2 norm；
3. 再计算全局 L2 norm；
4. 计算 `min(max_norm/(norm+1e-6), 1)`；
5. 原位缩放全部梯度。

阈值为官方代码的 `0.01`。给定同一参考梯度时，与 PyTorch 裁剪最大误差约 `4.89e-9`。

### 4.11 `siba_jittor/compat/pytorch_adam.py`

新增原因：Jittor 内置 Adam 与 PyTorch 1.10 的 epsilon 放置方式不同。

该实现保存：

- `exp_avg`；
- `exp_avg_sq`；
- `beta1/beta2`；
- bias correction；
- learning rate；
- epsilon；
- weight decay。

更新公式与官方 `torch.optim.Adam` 对齐。给定同一参考梯度时，更新后参数最大绝对误差约 `2.98e-8`。

### 4.12 `siba_jittor/train.py`

执行顺序：

1. 读取官方参数。
2. 根据 `args.use_gpu` 设置 `jt.flags.use_cuda`。
3. 构建 SIBA。
4. 构建 `PyTorchAdam` 和 Jittor `StepLR`。
5. 构建 `JointGrad` 和 `Fusionloss`。
6. 构建 batch size 4、shuffle=True、drop_last=False 的 Jittor Dataset。
7. 每 batch：
   - `model.train()`；
   - 清梯度；
   - 前向；
   - 计算三个损失；
   - 组合总损失；
   - `optimizer.backward(loss)`；
   - 全局 L2 梯度裁剪；
   - Adam 更新。
8. 每 50 batch 打印 epoch、学习率、loss 和 ETA。
9. 每 epoch 执行 StepLR。
10. 60 epoch 后保存 `SIBA_epoch60.pkl`。

保持了官方“只保存最终模型参数”的行为。缺点是没有 optimizer/scheduler 状态，不能从中间 epoch 精确断点续训。

### 4.13 `siba_jittor/test.py`

执行顺序：

1. 启用 Jittor CUDA。
2. 加载 `.pkl` checkpoint 中的 `model` 字典。
3. 创建 `TestLoader`，batch size 1，shuffle=False。
4. 模型融合红外和可见 Y。
5. 对输出 clamp。
6. 使用原可见 Cb/Cr 恢复 RGB。
7. 转 HWC 后保存 PIL 图像。

原代码在模型调用前后直接使用 `time.time()`，没有 GPU 同步。项目保留该协议用于复刻，同时在 `tools/run_inference.py` 中增加同步计时用于真实性能比较。

### 4.14 `siba_jittor/utils/RGB2YCrBb.py`

`RGB2YCrCb`：

- 从 RGB 计算 Y、Cr、Cb；
- 使用官方固定系数；
- 返回三个单通道张量。

`YCrCb2RGB`：

- 按 `[Y,Cr,Cb]` 拼接；
- 加 bias；
- 乘固定 3×3 变换矩阵；
- reshape 并 clamp 到 `[0,1]`。

Jittor 版增加 NumPy clamp 分支，便于辅助工具处理数组。核心 Jittor 张量路径不变。

### 4.15 `siba_jittor/utils/resize_resolution.py`

该文件与官方字节一致：

- 宽高分别整除 2；
- 使用 `Image.LANCZOS`；
- 红外和可见图采用相同处理。

## 6. 实验工具代码

### 6.1 源码与数据审计

- `tools/audit_source.py`：统计文件、行数、SHA256、类和函数；发现漏文件/漏符号。它不能单独证明语义等价。
- `tools/build_dataset_manifest.py`：图像配对、尺寸检查、SHA256 和可选固定 seed 抽样。
- `tools/combine_training_manifests.py`：合并 MSRS 与 RoadScene 训练清单，生成 1,283 对总清单。
- `tools/validate_dataset_manifests.py`：重新读取实际文件并验证清单哈希。
- `tools/prepare_training_dataset.py`：根据 manifest 生成统一训练目录，保证两框架使用同一批文件。
- `tools/prepare_test_datasets.py`：准备 MSRS、M3FD_2x、TNO 测试目录，并执行官方 M3FD 半分辨率处理。

### 6.2 训练和数值对齐

- `tools/run_training.py`：覆盖官方 args 中的数据路径、输出路径、epoch 和 GPU 编号，设置 Python/NumPy/框架 seed，然后原样执行对应 `train.py`。
- `tools/smoke_test_jittor.py`：用随机小张量验证前向、损失、反向、裁剪和一步更新是否可运行；不参与最终指标。
- `tools/export_pytorch_alignment.py`：从同一官方 checkpoint 导出 PyTorch 输入、参数、逐层激活、loss、梯度和一步更新。
- `tools/check_jittor_alignment.py`：读取相同输入和参数，在 Jittor 侧比较 706 个检查项。当前版本同时报告前向与损失、参考梯度下的裁剪与 Adam、原生训练步接近程度和严格训练步等价；历史原始报告的旧 `passed` 字段保留不改。

### 6.3 推理和框架比较

- `tools/run_inference.py`：统一运行 PyTorch/Jittor 推理，保存图像、逐图计时和 summary；支持同步与官方未同步计时。
- `tools/compare_fusion_outputs.py`：逐图检查文件名、尺寸、最大/平均像素误差和 PSNR。
- `tools/compare_framework_metrics.py`：比较相同权重下两框架的七项指标差异。
- `tools/compare_metrics_to_paper.py`：将三数据集汇总值与 `configs/paper_metrics.json` 比较。
- `tools/summarize_performance.py`：汇总同步延迟、FPS 和官方异步计时。

### 6.4 训练日志和可视化

- `tools/parse_training_logs.py`：解析官方每 50 batch 一次的 loss 日志，生成逐条 CSV、epoch 汇总和 loss 曲线。
- `tools/make_visual_grid.py`：把真实红外、可见、Jittor 和 PyTorch 输出排成对比图；只生成展示画布，不生成实验图像。
- `tools/plot_metric_comparison.py`：从真实指标 CSV 绘制定量图，不重新生成指标。

### 6.5 MATLAB 指标

- `tools/evaluate_official_metrics.m`：逐图计算 VIF、SCD、MI、Qabf、MEF-SSIM、MS-SSIM 和 FMI。
- `tools/run_matlab_evaluation.py`：批量调用 MATLAB，保存命令、stdout/stderr、return code、逐图 CSV 和汇总 CSV。

## 9. 产物应该如何解释

### 9.1 官方权重结果

`OfficialPyTorch` 与 `OfficialJittor` 使用作者发布的同一模型参数，是判断迁移正确性的主要实验。

- 706 张输出最大只差 1 个灰度级；
- 七项指标按论文三位小数基本一致；
- 说明模型结构、参数加载、前向和颜色恢复高度可信。

### 9.2 自训练结果

`PyTorchSelfTrained` 与 `JittorSelfTrained` 分别从各框架随机初始化开始训练。

它们不能当作严格配对实验，因为：

- 初始化参数未显式同步；
- shuffle 顺序不同；
- crop 调用顺序不同；
- 自动微分和 CUDA 算子存在差异。

它们的作用是证明训练代码可完整运行、loss 能下降、模型能生成有效融合结果，不是证明两条训练轨迹逐步一致。

### 9.3 对齐测试

受控 alignment 使用同一 checkpoint 和同一随机输入，更适合验证框架差异。

当前结果：

- 前向和 loss 高度接近；
- 自定义 clip/Adam 在参考梯度下接近 PyTorch；
- 真实梯度相对 L2 误差约 1.05%；
- 真实一步更新相对 L2 误差约 6.73%。

所以训练功能完整，但严格数值等价尚未完成证明。

## 13. 非算法代码边界

`ppt/make_ppt.py` 和 `ppt/make_ppt_v2.py` 只负责把论文图片、真实实验图表和文字排入 PPT。代码中的 `Image.new` 用于创建画布、遮罩或拼图背景，不参与训练、推理或指标计算。PPT 代码不应被当作算法迁移证据，也未发现其向实验结果目录写入伪造融合图或指标。
