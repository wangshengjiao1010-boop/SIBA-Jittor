# SIBA-Jittor 逐文件迁移最终审计

## 审计基线

- 论文：*The Source Image is the Best Attention for Infrared and Visible Image Fusion*，ICCV 2025。
- 官方仓库：`Afreshbird/SIBA`。
- 固定提交：`880a1ddf9eaa610c64e5f25f87fbb146448addc9`。
- 官方源码快照：`official_pytorch/`。
- Jittor 迁移目录：`siba_jittor/`。

## 审计方法

1. 对照全部 13 个官方 Python 文件的路径、类、函数、参数、执行顺序和返回值。
2. 逐行检查 PyTorch/Jittor 差异，区分框架语法替换、框架兼容实现和算法变化。
3. 对模型参数、主要中间激活、三项损失、梯度、梯度裁剪、Adam 一步更新和完整推理输出进行数值检查。
4. 对 1,283 对训练数据清单和 706 对测试数据清单记录文件名、尺寸和 SHA256。
5. 对训练日志、权重、指标 CSV、曲线和可视化结果建立 SHA256 完整性清单。

| `test.py` | 同路径 | 权重加载、逐图推理、YCbCr 回填、保存和官方计时 | 推理逻辑保持一致；权重扩展名改为 `.pkl` |

## 新增兼容文件

- `compat/pytorch_adam.py`：按 PyTorch 1.10 Adam 的偏置修正和 epsilon 位置实现更新。
- `compat/pytorch_clip.py`：按 PyTorch 1.10 的逐参数范数、全局范数和裁剪系数顺序实现。
- `compat/__init__.py`：包初始化文件，无算法逻辑。

## 数值证据

- 137 个参数张量、565,941 个参数，初始权重最大误差为 0。
- 中间激活最大绝对误差：`2.0206e-4`。
- 总损失最大绝对误差：`2.9802e-6`。
- 原生梯度余弦相似度：`0.999945`；相对 L2 误差：`1.0508%`。
- 一步参数更新余弦相似度：`0.997738`；相对 L2 误差：`6.7269%`。
- 使用相同 PyTorch 参考梯度时，梯度裁剪最大误差：`4.8894e-9`；Adam 更新最大参数误差：`2.9802e-8`。
- 官方权重下 706 张图像全部同名同尺寸，最大像素差为 1 个 uint8 灰度级。
- 官方权重的 7 项指标在三个数据集上均与论文表格三位小数一致。

## 不能过度表述的部分

1. 作者没有公开随机选取的 200 对 RoadScene 文件和随机种子，因此不能声称自训练数据与作者完全相同。
2. 论文写 RGB 到 YCbCr，官方训练代码实际按灰度读取；本迁移遵循官方代码。
3. 复现使用 RTX 3090 24 GB，论文使用 TITAN RTX 24 GB；运行时间不能作为同硬件复现。
4. 原生 Jittor 梯度和一步更新未达到 `0.1%` 相对 L2 的严格等价标准，因此只能表述为功能迁移完整、推理高度一致，不能表述为逐步严格相同。
