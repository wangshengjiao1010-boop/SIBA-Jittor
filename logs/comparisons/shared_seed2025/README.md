# Shared Seed 2025 Logs

`EXPERIMENT_COMPLETE` is the authoritative completion marker. `pytorch_train.log` and `jittor_train.log` contain console progress; the two `*_batches.csv` files contain all 19,260 batch records. Metadata records framework versions, shared input hashes, final checkpoint hashes, durations and output locations.

The original absolute AutoDL paths are retained in raw metadata for auditability. Portable repository paths are documented in the root README and result index.
