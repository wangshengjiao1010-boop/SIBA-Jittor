# Conda Environments

正式环境名称：

- `PytorchDome`
- `JittorDome`

安装：

```bash
bash scripts/setup_envs.sh
bash scripts/complete_env_setup.sh
```

完整实测包版本保存在：

- `logs/environment/pip_freeze_pytorch.txt`
- `logs/environment/pip_freeze_jittor.txt`
- `logs/environment/reproduction_environment.txt`

PyCharm 远程解释器与激活方式见 `docs/PYCHARM_REMOTE_GUIDE.md`。
